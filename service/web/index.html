接收端实际能力

投递前核对 Windows 公告；本机设置不能代替远端能力，过期公告不能用于新任务。



接入服务器

读取本机 simpleHtmlWatch 的可调度机器；选择后生成 SSH / 启动时间 / NPU 信息探测入口。机器名称与 ready 状态不代表 A5 身份或 NPU 空闲。







维护可登记并执行所选服务器上的命令，只能修改独立入口清单，不能修改模型密钥或扩大机器范围。选择后点击保存即生效；配置不等于实验已执行。








发布实验任务
选择接收端已经配置的实验入口。修改任务内容请增加 revision；重复运行请更换 run_id。


连接设置
密钥只保存到本机 Windows DPAPI / macOS 钥匙串，不写入任务、日志或 ZIP。


Pi 环境与工具
保存后用于下一次领取的任务。已有任务继续使用领取时的配置快照。环境说明会发送给所配置的模型，不进入公开结果 ZIP；请勿填写密码或 Token。










服务器控制 · simpleHtmlWatch
与 Pi 运行在同一台 Windows 上。先在 simpleHtmlWatch 中配置 SSH 机器；这里不需要复制 SSH 密码。ready 不代表 NPU 空闲。




实验入口配置
任务只能执行本机配置的入口。simpleHtmlWatch 入口须指定机器、机器组，或明确设置 allowAnyMachine。outputs 列出的结果才会进入公开 ZIP。


联网读取与搜索
Windows 可选择系统 curl，适用于 Node 只能访问回环的环境。此处代理只影响网页工具，模型继续使用连接设置中的本机网关。






自动上下文压缩
压缩会调用模型生成摘要并保留近期对话。任务 ID、执行证据和结果独立持久保存。
